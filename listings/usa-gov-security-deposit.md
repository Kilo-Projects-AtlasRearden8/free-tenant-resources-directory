# Security Deposit Return Checklist

**Category:** Move-in/move-out checklists  
**Cost:** Free ($0)  
**Source:** USA.gov  
**Official link:** https://www.usa.gov/tenant-rights

## Steps

1. Know your state's deadline for security-deposit returns.
2. Submit your forwarding address to the landlord in writing.
3. Document the unit condition with move-out photos.
4. Request an itemized list if any deposit is withheld.
5. Dispute improper charges through local legal aid if needed.

## About

USA.gov guidance on getting your security deposit back after moving out.
